# 日本語学習者の語彙検索行動のクラスター分析（予備分析）

大学院進学に向けた研究計画の予備分析として、日本語学習者の語彙検索行動をクラスター分析しました。

## データ
国立国語研究所「語彙検索行動情報データセット」（8つの国・地域、9大学、学習者110名、4,712件の検索記録）
https://www2.ninjal.ac.jp/jll/word_search/survey-data/information-sheet.html
※データは本リポジトリには含まれていません。上記サイトからダウンロードしてください。

## 分析の流れ
1. データクリーニング（表記ゆれの統一：全角・半角、大文字・小文字など）
2. 学習者ごとの行動指標の作成（22指標：検索回数、連続検索の割合、目的達成率、使用ツール、入力言語、入力方法など）
3. Zスコアによる標準化
4. k-meansクラスター分析（エルボー法・シルエット係数でクラスター数を検討）
5. クラスターと日本語レベルの関係（カイ二乗検定）
6. 所属大学による交絡の確認（同一大学内での順位相関分析）

## 主な結果
- 「Web探索型」（42名：連続検索が多く、Web・検索エンジンを使い、達成率がやや低い）と「アプリ単発型」（68名：辞書アプリで1回検索し、達成率が高い）の2タイプが見られた
- クラスターと日本語レベルの関係は有意ではなかった（χ²=6.77, p=0.080）
- 所属大学と日本語レベルが強く交絡していた
- 同一大学内でも、日本語レベルが高いほど検索回数（r=0.42, p=0.025）と連続検索の割合が増える傾向が見られた
- 示唆：検索行動は「検索の深さ」（習熟度と関連）と「ツールの選択」（学習環境と関連）の2つの側面に分けて考える必要がある

## 課題
- シルエット係数が低く（0.149）、明確なクラスター構造ではない
- サンプル数が少ない（110名）
- 今後は所属大学を統制したモデルや、階層的クラスター分析（Ward法）との比較を行う予定

## 環境
